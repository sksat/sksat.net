WebGPU Not Supported

This application requires WebGPU, which is not available in your browser.

For Firefox on Linux:

  1. Open about:config
  2. Set dom.webgpu.enabled = true
  3. Set gfx.webgpu.force-enabled = true
  4. Restart Firefox

For Chrome/Chromium:

  1. Open chrome://flags
  2. Enable "Unsafe WebGPU"
  3. Restart browser

Or try Chrome / Edge 113+ on Windows/macOS.
